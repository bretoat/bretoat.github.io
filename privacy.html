Privacy Policy

Last updated: November 11, 2026

Video Dashboard is a personal tool used only by its owner to view statistics for the owner's own YouTube, Instagram, and TikTok accounts. It is not available to the public.

What data is accessed

With the owner's permission, the app reads the owner's own channel and account information, a list of the owner's uploaded videos, and performance statistics for those videos (such as views, likes, comments, and watch time) through the official YouTube, Instagram, and TikTok APIs. It does not access data about any other person.

How data is used

The data is used only to display a dashboard to the owner. It is not sold, shared, or transferred to any third party, and it is not used for advertising.

How data is stored

Data and sign-in tokens are stored only on the owner's personal computer. The owner can revoke access at any time from their Google, Instagram, or TikTok account settings and can delete the stored data by deleting the app's files.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
